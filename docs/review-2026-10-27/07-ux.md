## ① 问题清单（按严重度）

### X-1 [P1] band 路径开面板可能拿不到键盘 → 字母漏进输入框
- 位置：`register.mjs:1587-1629`（toggle 同步 open，focus:true 仅是请求）；README:94-95 快速开始第 2 步直接写 "Press a hotkey or click"。
- 现象：TODO A1（官方类型依据：`PaneOpenArgs.focus` "请求不是授予"，band 被持有时拒绝）在 3.8.0 处置表中仍标注"实机热键表现仍待验"。若成立，按 m 打开面板后按 `t` 无反应——更糟的是按键落入 composer 变成正文，用户需察觉并退格。
- 为什么伤：这是新手第一分钟的主路径（README 第 1-2 步），失败形态是"静默错位"而非"明确报错"，最损信任。
- 建议：(a) 实机验证后，若确实无键盘：README 快速开始改为"打开后点击面板或 ctrl+x tab 获得键盘；纯键盘用 /ccsl"；(b) open 成功但 focus 未授予时 toast 一句提示（结果对象若含 focus 信息）；(c) 干脆把文档主入口换成 /ccsl + 键位绑定示例（README:136-145 已有）。
- 预期收益：消灭第一分钟挫败；[I]（代码路径 [V]，焦点授予行为未实机验证）

### X-2 [P1] fill 失败时面板已收起，反馈只剩一条易丢的 toast（用户假设——部分证实）
- 位置：`register.mjs:1469-1487`（先 close/invalidate 收起 → 再 `$.prompt.fill` → 失败仅 toast `ccsl: 无法填入（…）`）；inline 路径 `1655-1674` 同构。
- 评估：**成功路径无问题**——composer 里出现的文本本身就是最强反馈，toast 只是补充；"丢失位置感"假设在成功侧不成立。**失败侧成立**：面板已收起、composer 没内容、解释只有一条瞬时 toast，三重落空；重试还需重新打开启动器。refusal 的两种原因（`dialog`/`no_composer`）文案已区分 [V]，但载体太弱。
- 建议：fill 返回 `isFilled:false` 时重新展开启动器（或保持不收起直到 fill 成功——需验证 pane 打开时 fill 是否可用，当前注释表明 close 是为了让 composer 拿键盘，顺序不可轻动 [V:1466-1468]）；toast 无法持久时至少在 band 上留一个 dim `⚠ 上次填入失败` 直到下次成功。
- 预期收益：失败可恢复、可诊断。[V]（行为链）；toast 停留时长/位置 [I]

### X-3 [P2] usage 面板 `cost $X 会话` 标签失真
- 位置：`register.mjs:1785`；history 来自 `$.store` 跨会话恢复（`:1190-1194`），t.cost 求和的是滚动 240 条窗口。
- 现象：新会话第一分钟 `会话` 成本即非零（继承上一会话记录）；README:132 自己也说明窗口是跨会话滚动。tokens 行已诚实标注 `最近N次请求(含子代理)`（`:1774`）[V]，唯独 cost 行说"会话"。
- 建议：改 `cost $X 最近240次 · $Y 累计`，或真正按会话起点切片统计（turn 序号/时间戳均可）。
- 预期收益：数字可信度。[V]

### X-4 [P2] run 按钮无"运行中"视觉 + 一键执行与提示词确认制不对称

- 建议：(a) 运行中把该按钮 label 加后缀 `…` 或 dimColor（redraw 已有 invalidate 通道）；(b) 实装 TODO A6 的可选 `confirm:true` 双击确认（默认只给非只读命令）；(c) run 结果行已有绿/红 [V:1423]，保留。
- 预期收益：误触防护对齐确认制哲学。[V]

## 已验证无问题（单列）

- 打开即时性：toggle 的 open/close 在 press dispatch 内同步发出、无 await 前置 [V:1592-1610]，感知性能达标；inline 回退路径立即 invalidate [V:1611-1618]。
- Esc 语义清晰：所有 open 均 closeOnEscape，关面板即还键盘；/permissions 的对话框由 CC 自管，无冲突 [V]。
- 热键可见性：按钮渲染携带热键前缀（`f: 快速模式` 式，5/6/7.png 证实），首按钮 autoFocus [V:1385]。
- 配置错误不静默：configNote → 面板顶部 ⚠ 行 + /ccsl-buttons 回报接受/跳过计数 [V:1526-1529, 1305-1326]。

- 上下文预算告警文案与再武装逻辑（80%/90%，<70% 重置）[V:1275-1283]。
- 与状态栏职责分离：band 只剩 ＊ + `· 运行中`，无重复数据 [V:1630-1635，5.png 证实]。
- 色盲可达性：四分区除边框色外有 emoji+文字双通道（⚡✏🔗$ 形状各异），非纯色彩编码 [V:1114-1119]。
